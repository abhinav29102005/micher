Why Micher?

⚡

True Speed Bonding

Combine multiple interfaces for near-additive throughput. 100 Mbps WiFi + 50 Mbps Ethernet = ~150 Mbps.

📊

Real-Time Dashboard

Live speed gauges, per-link throughput graphs, and transfer progress — in both GUI and terminal.

🔌

Zero Config

Auto-discovers all network interfaces. No drivers, no kernel modules, no admin rights needed.

🐧

Cross-Platform

Works identically on Linux and Windows. GUI app with system tray, or powerful CLI for headless/SSH.

🐳

Docker Ready

Deploy the receiver as a Docker container on any VPS. One command to start accepting bonded transfers.

🆓

100% Free

No paid relay service, no subscription. Pure Python, stdlib sockets, open source forever.

🐳 Server Mode (Docker)

Run the receiver on any machine or VPS:

docker run -p 9191:9191 micher-server Copy
